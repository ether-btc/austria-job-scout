## Phase 6.1 (KMU pipeline) — ACTIVATED 2026-07-18

Per user request after the Day-1 recheck pipeline shipped
(`/srv/sync/company-recheck-2026-07/`), Phase 6.1 was activated as a
focus-area outside the `austria_job_scout` package:

- **Wire-up script**: `scripts/kmu_career_urls.py` lives in the
  scratch directory `/srv/sync/company-recheck-2026-07/scripts/`. It
  imports `kmu_wien_discovery.build_kmu_career_urls` from the package
  to expand the 536 domain-bearing companies in `scout_*.csv` into
  **8,576 candidate URLs** (`kmu_career_url_targets.csv`). No network
  is performed.
- **Net result**: 1 row in → ~8 URLs out (apex + `www.` variants +
  `jobs.<domain>` + `careers.<domain>` × `/karriere`, `/jobs`,
  `/karriere/jobs`, `/stellenangebote`, `/careers`, `/offene-stellen`).
- **Filter**: `_normalize_domain` rejects "nan" / "none" / "null" /
  empty / TLDless hosts — those would otherwise produce garbage
  `https://jobs.nan/` candidates from the day-1 enrichment artifacts.
- **Live fetch (next step, NOT DONE THIS SESSION)**: callers must pipe
  `kmu_career_url_targets.csv` through austria-job-scout's `fetch`
  subcommand under Pillar-0 budget (50/day residential, sequential).
  stealth-core binary was rebuilt this same session so the wreq-tier
  fallback works; rustls fallback (this build) is enough for ATS JSON
  + simple HTML career pages.
- **Tests**: existing `tests/test_kmu_wien_discovery.py` (12 tests,
  all passing since 2026-06-29) covers `build_kmu_career_urls` and the
  four source extractors. The wire-up script uses them as a library
  function. No new tests filed.

**Why this lives outside the package**: the package is "zero-network
library for austria-job-scout's discover/fetch stages". The Phase-6.1
wire-up *requires* an external input source (CSV from
company-quickcheck scout runs). Keeping it as a colocated script in
the scratch directory avoids polluting the library contract or adding
a 11th CLI subcommand.

If Phase 6.1 graduates from "wire-up wishlist" to "regular run", the
right next move is to add a `discover-kmu` CLI subcommand that accepts
a path to a scout CSV and outputs to `--out`. Until then, scripts live
in the scratch directory.
